## Binding and evidence

Raw UTF-8 route SHA binds Windows hostname/SID, profile/runner hashes, actual isolated
site/root/home/database fingerprint/prefix/owner/runtime manifest and bridge bytes,
plus exact tenant/original inquiry/source/operation/intent/request/reference digests.
The existing card's card_id is `route-` plus that SHA; no new review gate is created.
Each request/response pins its bytes, route, card and operation. The local host/profile
and remote actual owner/site/storage identity are independently checked. This is a
trusted existing SSH execution path, not a new cryptographic host attestation service.

Each native operation returns connection ID and checks transaction absence and named
lock release **while its connection is open**. The Windows transport double requires
the latest fresh read's proof. Process exit, EOF, sentinel, lengths and exact returned
pins must also pass; connection-close cleanup cannot substitute for the lock check.

Bounds:12 callbacks/run,240s/run,30s canonical remote call,40s adapter child,45s broker
operation;128KiB request/response. No automatic write retry. Timeout means remote
outcome unknown, not proof a remote process stopped. Private requests, responses,
claims and held receipts survive errors. Post-double loss tests retain the original
permit/digest and attempted observation, without claiming unknown counts are zero.
