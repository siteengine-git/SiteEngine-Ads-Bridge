# Install and import — Ads Bridge0.7.0

This build is main-Alma installed and Ads-verified. Final publication/delivery remains
pending the CRM-owned producer coexistence result recorded in DELIVERY.json.

1. Back up the existing Ads files and configuration/history before replacing the
   plugin. Finish an active saved configuration import with its original administrator
   and Resume workflow first. Do not clear journals or use Storage initialization
   to bypass it. Install the exact ZIP through WordPress Plugins→Add New→Upload,
   retaining configuration,data and active dependency versions.
2. Requirements:PHP8.3+,mysqli/ZIP,SiteEngine Base,Fluent Forms and FluentCRM3.2.6
   or3.3.1. This producer package's native Pro sequences require FluentCRM Pro3.3.1.
   Destinations do not need the separate CRM Configuration plugin. No profile,JSON
   editing,CLI command or manually installed MU file is part of ordinary setup.
3. Obtain the current portable configuration ZIP from the CRM authoring site's
   normal export/download. Open SiteEngine→Ads Bridge→Import CRM Configuration.
   Upload;select the actual destination form and Service input,compatible CRM
   fields,and service label. Base facts stay destination-owned/read-only.
4. Review changes. Compatible definitions are reused. Keep preserves a destination
   edit;Replace deliberately restores the package body. Unknown identities,active
   objects,unsupported relationships and incompatible field types stop for review.
5. Click Import configuration once. Explicit absent-storage initialization uses
   existing additive schema2/guard1 migrations;partial schemas or retained operations
   stop safely. Automatic bounded batches retain upload,mappings,IDs and progress.
   If interrupted,inspect its actual error and use Resume saved import. Missing
   returned IDs or unknown writes require the original owner's exact recovery.
6. Completion links to native FluentCRM editors. All optional source mappings may
   stay Unused. Incomplete lifecycle setup can save with automation disabled.
   Import leaves lifecycle automation,Sheets and every export family disabled.
   Complete actual Base,Consent,form/feed,account/credential prerequisites separately.
   Import success is not permission to send,enroll or advertise.

On a failed upgrade,restore only backed-up Ads files when no active operation needs
this importer. Preserve imported native content,settings,journals,inquiry history and
all Consent withdrawal barriers. No destructive uninstall,purge or whole-DB restore.
See the packaged docs/CRM-CONFIGURATION-IMPORT.md for exact recovery/adapter limits.
