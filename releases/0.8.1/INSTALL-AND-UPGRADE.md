Open Ads Bridge > Setup > Configuration authority.

1. A normal fresh installation can save incomplete settings immediately. CRM import,
   credential-file access and export readiness are separate prerequisites.

   those values and delivery flags before importing.
5. Save the desired Ads form, reopen it, and verify effective values. Shared business
   facts still come from Base. CRM configuration not imported does not mean a vendor
   dependency is missing or that mappings are valid; those checks remain separate.

path changes and removal. Earlier recorded explicit imports retain that intent.
Original files/wp-config.php are never edited or removed by the choice. No authority
